# Security controls

Each control is enforced server-side and proved by at least one negative test. Mapping keys: **A0x** = OWASP Top 10:2025, **LLM0x** = OWASP Top 10 for LLM Applications 2025, **ASIxx** = OWASP Top 10 for Agentic Applications 2026, **V#** = OWASP ASVS 5.0 chapter.

Tests marked *(live)* run against the compose stack via `make test-integration`; the rest run in CI via `make test`.

| ID | Control | Threat addressed | Mapping | Implemented in | Proven by |
|---|---|---|---|---|---|
| C-CFG-01 | Every credential (Keycloak bootstrap and dedicated admins, DB roles, web client secret, demo password) is generated by `make bootstrap`; the temporary bootstrap admin is deleted after a dedicated admin is created, and the dedicated admin's password never enters container configuration; no credential or credential fallback exists in tracked files; compose fails closed when a secret is missing; weak or default values are refused; published ports bind to `127.0.0.1` | Default/committed credentials; exposed admin console | A02, A07; V13 | `scripts/bootstrap.sh`, `docker-compose.yml` (`${VAR:?}`), `infra/keycloak/configure.sh` | `tests/security/test_bootstrap.py`, `tests/security/test_secret_hygiene.py`, `tests/security/test_compose.py::test_published_ports_bind_to_localhost`, `::test_secrets_have_no_fallback_values`, `tests/security/test_compose.py::test_dedicated_keycloak_admin_is_not_in_container_config`, `tests/security/test_keycloak_admin.py::test_default_admin_credentials_are_rejected`, `::test_bootstrap_admin_is_removed_after_seed` *(live)* |
| C-CFG-02 | Realm hardening: `sslRequired=external` (master left at the Keycloak default `external`), brute-force lockout (5 failures, up to 15 min), length-based password policy (15–128, not username/email), 5-minute access tokens, single-use rotating refresh tokens, 30-minute idle session; web client is confidential with S256 PKCE, exact redirect URIs, no implicit or password grant | Credential stuffing, token replay, code interception, open redirect | A07; V6, V7, V10 | `infra/keycloak/realm-northwind.json` | `tests/security/test_keycloak_realm.py`; `services/gateway/tests/integration/test_oidc_login.py` (`test_refresh_tokens_are_single_use`, `test_code_exchange_requires_client_secret`, `test_code_exchange_requires_matching_pkce_verifier`, `test_unregistered_redirect_uri_is_refused`, `test_password_grant_is_disabled`) *(live)*; `tests/security/test_keycloak_admin.py::test_generated_admin_can_authenticate_and_master_requires_tls_externally` *(live)* |
| C-AUTH-01 | Gateway access-token validation pins issuer, audience and asymmetric algorithms (RS256/ES256; symmetric algorithms cannot be configured); header `alg` must match the JWK selected by `kid`; requires `exp`, `iat`, `iss`, `aud`, `sub`; checks `nbf`; rejects non-access tokens (`typ` ≠ `Bearer`); JWKS cached with TTL, refreshed on rotation, refetch rate-limited against unknown-`kid` floods, fails closed when no keys are available | Token forgery, algorithm confusion, token substitution, IdP request amplification | A07; V9, V10 | `services/gateway/src/gateway/auth/tokens.py`, `services/gateway/src/gateway/auth/jwks.py`, `services/gateway/src/gateway/config.py` | `services/gateway/tests/test_auth.py` (wrong issuer, wrong audience, `alg=none`, expired, not-yet-valid, tampered payload, tampered signature, HS256 with public key, alg/key mismatch, unknown/missing `kid`, ID token), `services/gateway/tests/test_jwks.py`, `services/gateway/tests/test_app.py::test_symmetric_jwt_algorithms_cannot_be_configured` |
| C-DATA-01 | Two DB roles per service: `<svc>_migrator` owns the schema and is used only by one-shot migrate jobs; `<svc>_svc` (runtime) has explicit grants only (gateway: `SELECT` on tenants; orders: DML on business tables), no DDL, no `TRUNCATE`, no access to other schemas, the Alembic table or the Keycloak database; no role is superuser or can create roles/databases or bypass RLS | Privilege escalation via a compromised service; lateral movement between schemas | A01; V13 | `infra/db/init/01-databases.sh`, `services/*/migrations/versions/0002_grant_runtime_privileges.py`, `docker-compose.yml` (`*-migrate` jobs) | `tests/security/test_db_roles.py` *(live)*, `tests/security/test_compose.py::test_runtime_services_never_receive_owner_credentials` |

## Related hardening (M1R)

These fixes accompany the controls above; their formal controls are scheduled in later milestones.

| Change | Formal control | Proven by |
|---|---|---|

| `ENV` is validated (`development`/`test`/`production`, default `production`); docs and OpenAPI are disabled in production | C-CFG-03 (M2c) | `services/gateway/tests/test_app.py::test_docs_hidden_in_production`, `::test_unknown_environment_is_refused`, `::test_settings_default_to_production` |
